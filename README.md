# Mapa de Envolvidos e Conexões

Mapa interativo que visualiza pessoas, empresas e casos citados em investigações jornalísticas, com suas conexões documentadas ou alegadas.

🔗 **Ver o mapa ao vivo:** https://vercel-deploy-one-blush-98.vercel.app

## Sobre

- **Documentado**: o vídeo/reportagem apresenta como fato ou relatório da PF/imprensa.
- **Alegado ou contestado**: hipótese, suspeita ou algo que o citado nega.
- Fonte: transcrição do vídeo do canal Revelando e reportagens citadas.

> Todas as pessoas e empresas citadas negam ou contestam irregularidades; nada aqui é condenação.

## Contribuindo

Este projeto está em expansão contínua — mais conteúdo sobre cada pessoa/conexão será adicionado ao longo do tempo. Contribuições, correções e fontes adicionais são bem-vindas via issues ou pull requests.

## Rodando localmente

É um único arquivo HTML autocontido. Basta abrir `index.html` no navegador, ou servir com qualquer servidor estático:

```bash
npx serve .
```

## Deploy

Hospedado na [Vercel](https://vercel.com). Todo push na branch `main` gera um novo deploy automático.
